# Arena Chat Exporter

Расширение для Chrome, Chromium и Brave на Manifest V3. Встраивает меню экспорта прямо в страницы `arena.ai` и `chat.lmsys.org`, парсит Direct и Side-by-Side чаты и сохраняет историю в удобных форматах.

## Возможности

- Экспорт Direct и Side-by-Side чатов.
- Direct-чаты, где Arena предлагает на выбор два ответа: оба ответа попадают в экспорт с подписями «вариант 1 из 2» / «вариант 2 из 2» и больше не принимаются за баттл.
- Форматы: `TXT`, `Markdown`, `HTML`, `PDF`.
- HTML-экспорт сохраняет читаемую разметку: запрос пользователя сверху, левый и правый ответы в колонках.
- PDF-экспорт сохраняет Unicode-текст визуально без `????`; для надежного копирования текста лучше использовать HTML или TXT.
- Режим чата определяется по совокупности признаков (подпись селектора режима, имена моделей на слайдах, геометрия «слота» ответа), а не по принципу «на странице есть карусель — значит баттл».
- Ручной переключатель `Режим чата` (`Определять автоматически` / `Direct чат` / `Side-by-Side`) на случай очередного редизайна Arena.
- Встроенная диагностика: по кнопке показывает, почему режим определён именно так, сколько найдено каруселей и слайдов, какие селекторы сработали, плюс `Копировать отчёт`.
- Настройки подписей ответов: `1 / 2`, `Left model / Right model`, `AI`, реальные имена моделей в заголовке или у каждого сообщения.
- Настраиваемые отступы между сообщениями: обычный режим дает 3 пустые строки, большой режим дает 8.
- Медиа (`img`, `svg`, `canvas`, `video`) заменяются на плейсхолдеры вида `[Медиа 1]`.
- Интерфейс EN/RU/DE/ES/PT с переключателем в меню.
- Настройки сохраняются через `chrome.storage`.

## Установка

1. Открой `chrome://extensions/`.
2. Включи `Developer mode` / `Режим разработчика`.
3. Нажми `Load unpacked` / `Загрузить распакованное расширение`.
4. Выбери папку `chrome-extension`.
5. Обнови страницу чата.

## Использование

1. Открой чат на `arena.ai` или `chat.lmsys.org`.
2. Дождись блока `Export Chat` / `Экспорт чата` под полем ввода.
3. Выбери язык интерфейса, формат, подписи моделей, разделитель и при необходимости режим чата.
4. Включи `Спрашивать папку сохранения` только если нужен системный диалог выбора папки.
5. Нажми нужную кнопку экспорта.

## Про папку сохранения

Chrome не дает расширениям читать путь, выбранный пользователем в системном диалоге сохранения. Поэтому расширение не может само “запомнить” конкретную папку.

Рабочая схема такая:

- если включено `Спрашивать папку сохранения`, Chrome показывает диалог и сам обычно помнит последнюю выбранную папку;
- если выключено, файл сохраняется без диалога в стандартную папку загрузок браузера.

По умолчанию диалог выключен, чтобы не искать папку при каждом экспорте.

## Техническая архитектура

- `content.js` парсит DOM, форматирует TXT/Markdown/HTML/PDF и генерирует Data URI.
- `background.js` не работает с DOM, `Blob` или `URL.createObjectURL`; он только вызывает `chrome.downloads.download`.
- UI внедряется в страницу через content script и обновляется через `MutationObserver`.
- Локальные библиотеки лежат в `lib/`, без CDN.

## Тесты

Запуск статических релизных проверок из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File chrome-extension/tests/static-checks.ps1
```

Запуск регрессионных тестов парсера (Node 18+, jsdom, синтетические снимки DOM Arena):

```bash
cd chrome-extension/tests
npm install
npm test
```

Тесты покрывают раскладку «два ответа в Direct-чате», оба варианта Side-by-Side, отсутствие подписи режима, закрытый выпадающий список режимов, ручной override и запасной разбор.

## Определение режима

Бейдж режима в панели показывает, насколько определению можно доверять:

- `Режим: Direct` / `Режим: Side-by-Side` — уверенное определение;
- `Режим: Direct (?)` — на странице нет явного маркера, выбран сценарий «несколько вариантов ответа». Экспорт работает, но режим можно выставить вручную;
- пунктирный бейдж — автопределение неуверенное или включён ручной override.

Кнопка `Диагностика` показывает причину (`mode-selector-label`, `shared-slide-models`, `distinct-slide-models`, `answers-in-one-slot`, `ambiguous-carousel`, `manual-override`) и количество слайдов/моделей.

## Ограничения

- PDF рассчитан на визуальный архив. Для копируемого текста и Side-by-Side разметки лучше использовать HTML.
- Для `chat.lmsys.org` есть best-effort fallback, потому что DOM может отличаться от Arena snapshots.
- Если Arena снова поменяет разметку, режим может определиться как `(?)`. Используй переключатель `Режим чата` и приложи вывод `Копировать отчёт` к баг-репорту.


## 🛡️ Безопасность и Аудит

Прозрачность — это основа доверия. Вот почему использование этого расширения безопасно:

1. **100% Локальная работа**: Вся обработка (создание PDF, конвертация в Markdown) происходит прямо в вашем браузере. Данные никуда не передаются.
2. **Отсутствие внешних запросов**: Расширение не использует `fetch` или `XMLHttpRequest` для связи с внешними серверами. Здесь нет никакой телеметрии или скрытого сбора статистики.
3. **Локальные зависимости**: Библиотеки `html2pdf.js` и `turndown` включены непосредственно в проект (папка `/lib`). Мы не подгружаем скрипты из облаков или сторонних CDN.
4. **Manifest V3**: Проект соответствует актуальным стандартам безопасности Chrome, которые запрещают выполнение удаленного кода.
5. **Открытый код**: Каждая строчка кода доступна для проверки. В папке `/tests` вы можете найти скрипт `static-checks.ps1`, который используется для проверки целостности и безопасности расширения.
