# Дорожная карта

Это потенциальные направления развития Arena Chat Exporter. Это не обещание релиза, а список идей, которые хорошо ложатся на текущую архитектуру парсера.

## Ближайшие улучшения


- Добавить предпросмотр экспорта перед скачиванием.
- Добавить шаблоны имен файлов.
- Добавить экспорт только выбранного диапазона сообщений.

## Форматы

- JSON-экспорт со структурой `rounds`, `user`, `left`, `right`, `modelName`.
- CSV/TSV для анализа баттлов в таблицах.
- Улучшенный PDF с полноценной Unicode-поддержкой и сохранением части Markdown-разметки.

## Удобство

- Профили настроек: `LLM handoff`, `Archive`, `Model comparison`.
- Быстрое копирование результата в буфер обмена без скачивания.
- Отдельный режим “анонимный датасет”, который жестче чистит имена моделей и метаданные.

## Парсер

- Больше эвристик для Gradio/Svelte DOM.
- Автотесты на сохраненных HTML-снимках Direct и Side-by-Side.
- Диагностический режим, который показывает, какие селекторы нашли сообщения и имена моделей.

## Публикация

- Подготовка Chrome Web Store package.
- Скриншоты и короткая демо-г GIF/видео для GitHub README.
- Issue templates для багов парсинга DOM.
